# Generated KiCad footprints

15,450 footprints across 155 installed libraries.

Generated TypeScript metadata and unmodified native `.kicad_mod` geometry from
[KiCad footprint libraries](https://gitlab.com/kicad/libraries/kicad-footprints).
Copyright KiCad library contributors. This collection adds TypeScript metadata;
it retains the [KiCad library license](LICENSE.md), CC BY-SA 4.0 with KiCad's design exception.

Regenerate using `ts-kicad generate-footprints [footprint-directory]`.
Import individual libraries through `ts-kicad/footprints/Capacitor_SMD`, etc.
Native geometry is bundled; 3D model references are retained and models are copied
into exported projects when installed locally. The entire 3D model collection is
not bundled.
