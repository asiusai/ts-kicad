# Component provenance

`download.ts` retrieves public EasyEDA/LCSC assets using
[easyeda2kicad 1.0.1](https://github.com/uPesy/easyeda2kicad.py). The converter is
an external tool; its Python source is not bundled with ts-kicad. All scripts
maintained in this repository are TypeScript.

The two resistors share one R0603 footprint; the circuit uses the builtin `r`
symbol. A complete download provides ten symbols, nine footprints and eighteen
STEP/VRML model files. Native assets live together in `lib/components/`, with
`symbols.ts` and `footprints.ts` generated by `ts-kicad sync`.

Corrections applied by the recipe:

- Replace missing electrical types with passive terminals. The circuit refines
  MOSFET gate and switch control/supply types using explicit pin type overrides.
- Treat unnumbered locating holes as non-plated rather than zero-annulus plated
  holes. Positions and sizes stay unchanged.
- Move the 212528 connector body outline to the fabrication layer because it
  crosses the solder-mask openings.
- `sync` normalizes legacy footprints and binds the colocated 3D model paths.

The design is approved for public inclusion. Third-party download rights are
separate from the design and the converter's license. EasyEDA's
[library documentation](https://docs.easyeda.com/en/Schematic/Libraries/) and
[terms](https://easyeda.com/page/legal) do not provide a single explicit
redistribution license covering every downloaded model. Downloads and native
outputs containing those assets are therefore kept out of this repository;
users retrieve them from the source. The KiCad builtin library license does not
apply to these downloads.
