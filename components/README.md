# Generated KiCad components

Generated from the installed KiCad 10 symbol libraries: 22,860 symbols in 223 libraries.
Regenerate with `ts-kicad generate-components [symbol-directory]`.
All declarations are TypeScript. Pin mappings, inheritance, descriptions, and
reference prefixes come from the source libraries. Descriptive metadata is JSDoc;
footprint hints do not assign project BOM choices.

Source: [KiCad symbol libraries](https://gitlab.com/kicad/libraries/kicad-symbols).
Copyright KiCad library contributors. This is a modified library collection:
native symbol definitions have been converted into TypeScript component classes.
The collection retains the [KiCad library license](LICENSE.md), CC BY-SA 4.0
with KiCad's design exception. The surrounding ts-kicad program is separate.

Format reference: [KiCad symbol library format](https://dev-docs.kicad.org/en/file-formats/sexpr-symbol-lib/).
